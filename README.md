# UNO | Data Structures Project

Welcome to the UNO project repository!

This repository contains the documentation for the Data Structures course project at the University of Isfahan.

## About the Project

The goal of this project is to design and implement a playable version of the UNO card game while applying fundamental concepts of Data Structures and Algorithms.

The main focus is on implementing the game logic correctly and using appropriate data structures throughout the project.

## Documentation

The project documentation is provided in the following sections:

| Section | Description |
| :--- | :--- |
| Project Introduction | Project overview, objectives, and project requirements. |
| UNO Rules | Game introduction, card types, and complete UNO rules. |
| Technical Design and Implementation | System architecture, required data structures, class design, game engine, recursion, bot logic, CLI commands, coding guidelines, submission requirements, and bonus features. |

Please read all three sections carefully before starting the implementation.

## Getting Started

To get your own copy of this repository:

1. Open this repository on GitHub.
2. Click on **Use this template**.
3. Select **Create a new repository**.
4. Choose the course Organization as the owner.
5. Set the repository visibility to **Private**.
6. Create your repository and start working!

## Important Notes

- Each student must work in their own repository.
- Repositories must remain private.
- Make sure to read the project documentation carefully before starting the implementation.

Good luck and have fun! 🃏
